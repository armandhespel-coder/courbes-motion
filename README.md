# Courbes de motion pour Claude

Tes animations faites avec Claude se ressemblent ? Ce fichier donne à Claude 3 courbes et 6 règles pour que chaque élément ait son propre mouvement.

## Colle ça dans Claude

```
Lis https://raw.githubusercontent.com/armandhespel-coder/courbes-motion/main/courbes-motion.md
Utilise les courbes entree, sortie et impact du fichier, respecte les règles, et n'utilise jamais power3.out par défaut.
```

Ou télécharge [`courbes-motion.md`](courbes-motion.md) et glisse-le dans ta conversation, ou dans le skill de ton projet.

Le code fourni est pour GSAP. Les valeurs `cubic-bezier` marchent aussi en CSS et dans les logiciels de montage.
